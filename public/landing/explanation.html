3. 2Factor.in SMS OTP 2FA Authentication Engine

High-Reliability 2-Factor Mobile Security Infrastructure

How 2Factor.in OTP Operates in SPEAXA:
OTP Generation & Dispatch: When a student or teacher enters their mobile number, SPEAXA calls 2Factor.in API (`https://2factor.in/API/V1/{API_KEY}/SMS/{MOBILE}/AUTOGEN`) to dispatch a high-priority 6-digit SMS OTP code.
Session Binding: The 2Factor transaction ID is bound to PostgreSQL `otp_tokens` with a strict 10-minute expiration window.
Real-time Verification: On OTP entry, the backend verifies the code directly with 2Factor servers (`AUTOVERIFY`). Upon success, a secure JWT session token is returned.
